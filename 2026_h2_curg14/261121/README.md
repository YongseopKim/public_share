## 1. AI Agent에게 일을 맡기기

### 1.1 이전 발표에서 말한 Agent

- Agent-payment 발표에서 말한 Agent에서 출발
- Agent는 행하는 자, 또는 다른 사람을 대신해 행하는 자
- 이 글에서 다룰 AI Agent는 [LLM을 통해 다음 행동을 판단하고 실행하는 소프트웨어](https://www.anthropic.com/research/building-effective-agents)
  - 정해진 구매를 반복하는 정기배송과 달리, 목표와 예산에 맞춰 무엇을 언제 얼마에 살지 판단하는 리테일 Agent
- Agent에게 일을 맡기면 한 사람이 해낼 수 있는 일은 얼마나 달라질까?
- 그렇게 일하는 사람이 많아지면 사업과 사회는 어떻게 달라질까?

Bot vs AI Agent
- 여기서 Bot은 정해진 환경을 정해진 규칙에 따라 지각하고 판단해 행동하는 프로그램
- 정기배송은 지정된 구매를 반복하고, 리테일 Agent는 목표와 예산 안에서 구매 내용을 판단
  - 왼쪽은 날짜를 확인해 미리 지정된 구매를 실행
  - 오른쪽은 가격과 후보를 확인해 구매 내용을 정하고 결과를 다음 판단에 반영
- 이 예시는 구매 권한(결정권)까지 맡긴 경우

```text
       Bot: 정기배송                      AI Agent: 리테일 Agent

 +------------------------------+   +--------------------------------+
 | 사람                         |   | 사람                           |
 | 상품, 금액, 주기를 지정      |   | 목표와 예산을 지정             |
 +--------------+---------------+   +--------------+-----------------+
                |                                  |
                v                                  v
 +------------------------------+   +--------------------------------+
 | 프로그램                     |   | AI Agent                       |
 |                              |   |                                |
 |  +--> 정해진 날짜 확인       |   |  +--> 현재 가격 확인           |
 |  |           |               |   |  |           |                 |
 |  |           v               |   |  |           v                 |
 |  |    정해진 상품 선택       |   |  |    후보 비교                |
 |  |           |               |   |  |           |                 |
 |  |           v               |   |  |           v                 |
 |  |    정해진 금액으로 결제   |   |  |    무엇을, 언제, 얼마에     |
 |  |           |               |   |  |    살지 판단                |
 |  |           |               |   |  |           |                 |
 |  |           |               |   |  |           v                 |

 |                              |   |                                |
 +------------------------------+   +--------------------------------+

 사람이 지정한 구매를 반복             목표 안에서 구매 내용을 다시 판단
```

### 1.2 노동과 판단, 그리고 결정권

- 노동: 자료를 찾고 계산하고 문서를 만드는 등 목표를 이루기 위해 수행하는 작업
- 판단: 자료와 상황을 해석하고 선택지를 비교해 다음에 무엇을 할지 고르는 일
  - 판단도 넓은 의미에서는 노동에 포함되지만, 여기서는 작업 수행과 다음 일을 고르는 판단을 나누어 봄
- 결정권: 주문이나 계획을 확정해 실제 구매와 다른 사람의 업무를 진행시킬 권한

세제를 고르는 Agent에게 맡긴 일을 비교
- 비교와 조사까지만 맡겼다면 실제 주문은 사람이 확정
- 다음에 조사할 대상을 고르는 것과, 돈을 써서 주문할 권한을 갖는 것은 다름

| 맡긴 것 | Agent가 하는 일                                                                             | 사람이 얻는 이득                                            |
| ------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 노동    | 여러 세제의 가격을 찾아 세탁 한 번당 가격으로 환산                                          | 상품마다 찾아서 계산하는 수고를 덜고 더 많은 후보 비교 가능 |
| 판단    | 가장 싼 세제가 필요한 날보다 늦게 도착한다는 결과를 보고 배송일을 맞출 다른 판매자까지 조사 | 다음 조사 대상을 다시 정해 주지 않아도 됨                   |

### 1.3 현실 사례: 월간 보고를 AI Agent에게 맡긴다면?

- 경영기획팀이 다음 달 판매 목표를 정하기 위해 이번 달 실적을 검토
  - 담당자는 ERP 실적과 엑셀 계획을 대조하고 보고용 PPT를 작성
  - 매출은 계획대로인데 이익이 모자란 제품군에서 단가와 원가를 확인
  - 그것으로 설명되지 않으면 마진이 낮은 제품이 더 많이 팔렸는지 판매 비중까지 조사

같은 자료와 보고 마감을 두고 조사와 보고 준비를 Agent에게 맡김
- 왼쪽은 담당자가 조사와 검토를 수행하고, 오른쪽은 Agent가 조사와 보고 준비를 맡고 담당자가 근거와 예외를 검토

### 1.4 결정권까지 맡기면?

- 지금까지는 Agent가 조사하고 사람이 결정
- 보고서가 빨리 나와도 목표가 확정되어야 생산팀과 구매팀이 다음 일을 진행
- 그 확정까지 맡기면 조사와 보고를 넘어 실제 생산과 발주를 움직이는 일까지 Agent가 수행

같은 회사에 제품 A, B, C의 추가 생산 기회가 있는 상황
- 자금과 생산 여력은 충분하지만, 같은 기간에 팀장이 한 제품의 검토만 마칠 수 있다고 가정
- 결정권을 주면 Agent가 찾아낸 기회를 사람이 건마다 승인하지 않아도 실제 사업으로 진행할 수 있음
- 그 결과 같은 기간에 생산하고 판매할 수 있는 양이 늘어나지만, 잘못된 판단에 투입되는 돈과 인력도 함께 커질 수 있음
- 이 그림은 사람의 검토가 사업 진행을 제한하는 경우의 비교이며, 실제 확대 규모는 수요, 자금, 설비와 위임 범위에 따라 달라짐
- 한 사람이 직접 검토할 수 있는 범위를 넘어, 자기 자원으로 사업을 벌일 권한을 Agent에게 주는 것

                                       생산   생산   생산

                                       +

                                       지출과 재고도 함께 확대

## 2. AI Agent에게 일을 맡긴다면, 무엇이 달라질까? 과거를 통해 추정해보기

- 한 사람이 직접 갈 수 없는 곳, 다 살필 수 없는 일까지 맡기면 무엇이 가능해질까?
- 누가 기회를 얻고, 잘못됐을 때 누가 손실을 감당할까?

### 2.1 사업 규모: 한 사람이 벌일 수 있는 일의 규모가 커진다

- 자신의 시간을 같은 비율로 늘리지 않고도 더 많은 생산과 거래를 진행할 수 있음
- 노동을 맡기면 직접 처리하는 수고가 줄고, 같은 시간에 처리할 수 있는 양이 늘어남
  - 스프레드시트에 재계산을 맡기면 주문 수량이 달라질 때마다 모든 금액을 다시 계산하지 않고 여러 견적을 비교할 수 있음
- 판단을 맡기면 중간 결과마다 다음 일을 정해 줄 필요가 줄고, 여러 현장의 일을 함께 진행할 수 있음
- 결정권까지 맡기면 본인의 건별 승인을 기다리지 않고 자본과 인력을 실제 사업에 투입할 수 있음
- 준비된 자원으로 더 많이 생산하고 거래하면 매출과 이익을 늘릴 기회도 생김
  - 일을 맡긴 대가와 운영 비용, 잘못된 결정으로 생긴 손실을 빼고도 남아야 이익이 증가

(13세기) 제노바 투자자 사례
- 제노바의 투자자는 밑천을 대고 항해 상인은 현지에서 장사
- [첫 기항지를 세우타로 정하고, 이후 행선지는 상인이 고르도록 함](https://escholarship.org/content/qt6px5817r/qt6px5817r_noSplash_6914ae1826f8d1dd399dd5cbfd2ab758.pdf#page=31)
- 상인은 현지 사정을 보고 다음 거래를 진행하고, 투자자는 직접 항해하지 않고 자본을 운용
- 직접 동행할 때와 비교하면 동시에 운용하는 자본은 3 / 1 = 3배
- 같은 돈을 여러 번 쓰는 것이 아니며 상인도 더 필요함

```text
  가정: 같은 투자자에게 세 항해에 댈 밑천이 이미 있음
        항해마다 필요한 밑천은 같음

  직접 동행해야 한다면                상인들에게 맡긴다면

        투자자                              투자자
          |                                   |
          | 동행                  +-----------+-----------+
          v                       |           |           |
       항해 A                     v           v           v
                               상인 A      상인 B      상인 C
                                  |           |           |
  항해 B와 C에 쓸 밑천은 대기      v           v           v
                               항해 A      항해 B      항해 C

```

### 2.2 하는 일의 변화: 사람이 직접 하는 일이 달라진다

- 일을 맡기면 직접 하던 업무가 줄거나 없어지고, 그 일을 다른 사람이나 회사가 수행하게 됨
- 작업만 맡기는지, 판단이나 결정권까지 맡기는지에 따라 내가 계속 해야 할 일도 달라짐

### 2.3 함께 일하는 방식: 사람과 회사가 함께 일하는 방식이 달라진다

- 일을 맡기는 범위가 달라지면 회사 사이에서 누가 결정하고, 누구의 결정을 받아 일을 진행하는지도 달라짐
- 한 회사가 모든 건을 직접 결정하고 다른 회사들이 그 응답을 기다리던 관계에서, 권한을 맡은 회사의 결정으로도 함께 일을 진행하는 관계로 변화

---

(1970년대, 전신 NBI) [Visa의 대행 승인](https://usa.visa.com/dam/VCOM/download/about-visa/visa-rules-public.pdf#page=907)

- 카드 발급사가 응답하지 못하면 Visa 승인망이 발급사의 기준과 대행 범위 안에서 대신 승인하거나 거절

- 가맹점: 고객의 카드를 받아 상품이나 서비스를 판매하는 가게
- 카드 발급사: 고객에게 카드를 발급하고 결제 승인 여부를 정하는 회사
- Visa 승인망: 가게의 승인 요청과 카드회사의 응답을 전달하는 망

대행 승인 권한을 맡기면 회사별 역할이 달라짐

- 카드회사는 직접 승인할 수 없는 경우를 위해 승인 기준과 대행 범위를 미리 정함
- Visa 승인망은 요청과 응답을 전달하는 데서 더 나아가, 그 범위에서 개별 거래를 대신 승인하거나 거절
- 가게는 카드회사의 직접 승인뿐 아니라 Visa의 대행 승인도 판매를 진행할 근거로 받아들임
- Visa가 판단 결과를 카드회사에 보고하고 다시 허락받는 절차라면, 카드회사가 응답하지 못할 때 거래를 이어갈 수 없음

함께 일하는 방식에서 달라진 점

- 카드회사에 요청을 전달하고 답을 기다리는 관계에서, 카드회사가 정한 범위 안에서는 Visa가 결정하고 가게가 그 결정에 따라 판매하는 관계로 변화
- 권한을 맡은 회사가 결정하는 것에 더해, 다른 회사들이 그 결정을 받아 실제 업무를 진행
- 그 결과 카드회사 한 곳이 응답하지 못해도 여러 가게가 승인 가능한 거래를 이어갈 수 있음
- 한 회사의 업무 중단이 다른 회사들의 판매 차질과 매출 손실로 번지는 것을 줄임

### 2.4 이익과 위험의 배분: 이익과 위험을 나누는 방식이 달라진다

- 자기 밑천으로 직접 장사한다면 자본을 제공하는 사람과 거래를 판단하는 사람이 같음
- 다른 사람에게 밑천을 맡기면 두 역할이 나뉨
  - 투자자는 돈을 대지만, 현장에서 무엇을 사고 어디서 팔지는 상인이 판단
  - 상인이 장사를 잘하도록 어떤 보상을 줄 것인지, 손실이 생기면 누가 부담할 것인지도 정해야 함
- 결정할 권한을 맡기는 것과 함께, 성과와 위험을 나누는 관계가 만들어짐

---

(중세) [베네치아의 콜레간차(colleganza)](https://diegopuga.org/papers/Puga_Trefler_QJE_2014.pdf#page=17)

- 투자자가 밑천을 제공하고, 항해 상인이 그 밑천으로 장사한 뒤 이익을 나누는 계약 방식
- 투자자는 직접 항해하지 않고 무역에 참여
- 상인은 자기 밑천이 부족해도 거래 능력과 노동을 제공해 사업에 참여하고 이익을 얻을 수 있음
- [이익을 나누는 약속과 함께, 손실이 생겼을 때의 부담도 정함](https://diegopuga.org/papers/Puga_Trefler_QJE_2014.pdf#page=19)
  - 확인된 해상 손실은 밑천을 댄 투자자가 부담
  - 상인이 정산 약속을 어겼을 때는 자기 재산으로 배상

```text
       투자자                              항해 상인
          |                                    |
          |          장사할 밑천을 제공        |
          |----------------------------------->|
          |                                    |
          |                         현지에서 거래할 곳과 방법을 판단
          |                         밑천으로 물건을 사고팔며 장사
          |                                    |
          |          귀항 후 거래 결과를 정산  |
          |<-----------------------------------|


  이익이 났을 때
  -------------------------------------------------------
       투자자                              항해 상인
    자본을 제공한 대가로                 거래를 수행한 대가로
       이익의 몫을 얻음                     이익의 몫을 얻음


  손실이 생기거나 약속을 어겼을 때
  -------------------------------------------------------
     확인된 해상 손실                    상인의 정산 약속 위반
          |                                    |
          v                                    v
     투자자가 부담                       상인이 자기 재산으로 배상
```

---

이 관계에서 달라지는 것

- 투자자는 다른 사람의 판단과 노동으로 사업을 벌리고, 그 성과의 일부를 상인에게 지급
- 상인은 밑천을 전부 소유하지 않아도 사업의 성과를 나눠 받는 사람이 됨
- 투자자는 거래 결정권을 맡겼어도 밑천을 잃을 위험까지 모두 넘기지는 못함
- 상인은 현장에서 거래를 판단할 권한을 얻지만, 약속을 어겼을 때의 배상 책임도 짐
- 자본을 가진 사람, 일을 수행하는 사람, 이익을 얻는 사람, 손실을 부담하는 사람이 하나로 묶이지 않고 계약으로 연결됨

## 3. AI Agent의 미래

### 3.1 생산성의 증가

노동과 판단을 맡기면 [같은 시간에 더 많은 일을 처리](https://arxiv.org/abs/2304.11771v2)
- 노동을 맡기면 사람이 직접 자료를 찾고, 계산하고, 문서를 작성하는 수고가 줄어듦
- 판단까지 맡기면 중간 결과를 보고 무엇을 더 조사할지도 Agent가 정하므로, 사람이 다음 일을 일일이 지시할 필요가 줄어듦
- 그만큼 같은 인력과 시간으로 살펴볼 수 있는 업무의 범위가 넓어짐

---

앞서 본 경영기획팀의 월간 실적 보고로 돌아가 보면

- 담당자는 보고 마감까지 제품군별 실적을 분석하고, 이익이 계획에 못 미친 원인을 설명해야 함
- 직접 조사할 때는 차이가 큰 제품군부터 살피고, 시간이 부족하면 나머지는 실적과 계획의 차이만 보고하게 됨
- Agent에게 조사와 보고 준비를 맡기면, 담당자가 한 제품군의 근거를 검토하는 동안에도 다른 제품군의 조사를 진행할 수 있음

| 구분                    | 담당자가 직접 준비                                                       | AI Agent에게 준비를 맡김                                                |
| ----------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| 노동                    | 담당자가 ERP 실적과 엑셀 계획을 대조하고 보고용 PPT 작성                 | Agent가 자료를 대조하고 보고용 PPT 초안 작성                            |
| 판단                    | 담당자가 단가와 원가를 확인하고, 설명되지 않는 차이는 판매 비중까지 조사 | Agent가 단가와 원가를 확인하고, 설명되지 않는 차이는 판매 비중까지 조사 |
| 근거와 예외 검토        | 담당자가 조사한 근거를 확인하고, 근거가 약한 제품군과 예외를 추가 검토   | 담당자가 Agent의 근거를 확인하고, 근거가 약한 제품군과 예외를 추가 검토 |
| 같은 마감까지 얻는 결과 | 일부 제품군의 원인을 자세히 파악하고, 나머지는 실적 차이만 보고          | 더 많은 제품군의 원인을 파악해 보고할 수 있음                           |
| 결정                    | 팀장이 다음 달 판매 목표를 확정                                          | 팀장이 다음 달 판매 목표를 확정                                         |

- 생산성의 증가는 보고서의 개수가 아니라, 같은 시간에 원인까지 파악한 제품군이 얼마나 늘었는지로 볼 수 있음
- Agent의 결과를 검토하고 고치는 데 시간이 많이 들면 그 효과는 줄어듦

---

담당자의 미래

```text
  현재
  맡은 제품군의 자료를 대조하고, 원인을 조사하고, 보고서를 작성
       |
       | Agent가 조사와 작성을 맡을 수 있게 되면
       v
  이 담당자의 미래는?
       |
       +--> 더 많은 일을 맡음
       |    회사가 분석 범위를 넓히고, 그 일을 이 담당자에게 맡김
       |    -> 더 많은 제품군과 이상 징후를 살피는 사람이 됨
       |
       +--> 같은 범위를 맡되, 하는 일이 달라짐
       |    같은 제품군을 계속 맡지만 조사와 작성은 Agent가 수행
       |    -> 직접 자료를 만드는 일보다 근거와 예외를 검토하는 일이 커짐
       |
       +--> 맡는 일이 줄어듦
       |    회사가 분석 범위를 줄이거나, 업무 일부를 다른 사람에게 넘김
       |    -> 맡는 제품군이 줄거나 특정 예외만 확인하는 역할이 남음
       |
       +--> 기존 역할이 없어짐
            Agent가 조사와 작성을 수행하고, 남은 검토도 다른 사람이 맡음
            -> 다른 업무로 이동하거나 일자리를 잃을 수 있음
```

팀장의 미래

```text
  현재
  팀원들의 보고를 바탕으로 사업을 파악하고, 판매 목표를 결정
       |
       | Agent 덕분에 같은 팀이 더 넓은 범위를 분석할 수 있게 되면
       v
  이 팀장의 미래는?
       |
       +--> 더 많은 사업을 맡음
       |    늘어난 분석을 검토하고 결정하는 일을 감당할 수 있음
       |    -> 팀원을 같은 비율로 늘리지 않고 더 넓은 사업을 관리
       |
       +--> 같은 사업을 맡되, 관리하는 방식이 달라짐
       |    같은 사업을 더 적은 인원으로 운영할 수 있게 됨
       |    -> 자료 취합과 보고 준비를 지휘하는 일은 줄고 사업 결정은 유지
       |
       +--> 맡는 범위가 줄어듦
       |    일부 사업을 다른 책임자에게 넘기거나 관리할 조직이 작아짐
       |    -> 더 작은 팀을 맡거나 직접 실무를 함께 수행
       |
       +--> 기존 역할이 없어짐
            상위 책임자나 다른 팀장이 Agent를 활용해 해당 사업까지 관리
            -> 중간 관리 역할이 통합되면서 팀장 자리가 없어질 수 있음
```

- 회사는 늘어난 처리 능력으로 분석과 사업의 범위를 넓힐 수도 있고, 기존 업무를 더 적은 인원으로 수행할 수도 있음
- 생산성이 높아지는 것만으로 담당자와 팀장의 지위나 보상이 함께 높아지는 것은 아님
- 더 많은 문제와 기회를 찾아내도 팀장의 결정을 기다리면, 그 분석이 실제 사업의 변화로 이어지지 못할 수 있음
- 그렇다면 분석을 바탕으로 예산을 배정하고 사업을 시작할 결정권까지 Agent에게 맡기면 무엇이 달라질까?

### 3.2 사업 주체로의 Agent

Agent가 결정권까지 갖게된다면, 실제로 사업을 시작할 수 있음

가상 사례: 같은 회사에 여러 제품의 추가 주문이 들어온 상황
- Agent가 제품별 추가 생산 물량과 예상 이익을 계산해 사업안을 준비
- 판단까지만 맡기면 사업안이 준비돼도 팀장이 승인한 건부터 돈과 인력을 투입
- 결정권까지 맡기면 Agent가 허용된 범위에서 집행과 예산 배정까지 확정
- 팀장이 사업안마다 검토하고 집행 여부를 정하던 일 중, 위임 조건에 맞는 안의 결정은 Agent가 수행
- 해당 사업안은 팀장의 결재 목록을 거치지 않고 예산 배정과 발주로 이어짐
- 위임 범위를 넘거나 근거가 엇갈리는 안은 사람이 결정하되, 그 일을 기존 팀장에게 계속 맡길지는 회사의 조직 운영에 따라 달라짐
- 잘못된 판단도 실제 지출로 이어지므로, 회사는 매출을 늘릴 기회와 함께 팔리지 않은 재고와 투입 자금의 손실도 떠안음

### 3.4 미래를 어떻게 대비할 것인가

Agent가 아닌 나를 찾을 이유가 있을까?
- 이런 미래 사회의 모습에서 우리는 어떤 경쟁력을 가져야 할까?
- 고객이 다른 선택지보다 나에게 맡길 이유가 있는지 봐야 함
- 여기서 고객에는 서비스를 구매하는 사람과 나를 채용하는 회사가 모두 포함

```text
                 고객이 해결하고 싶은 일이 있음
                              |
                              v
                    누구에게 맡길 것인가?
                              |
            +-----------------+-----------------+
            |                 |                 |
            v                 v                 v
       고객이 직접        다른 사람이나       나에게 맡김
       Agent를 사용       회사에 맡김         나도 Agent를 사용
            |                 |                 |
            |            상대도 Agent를         |
            |            사용할 수 있음         |
            |                 |                 |
            +-----------------+-----------------+
                              |
                              v
                  고객이 원하는 결과를 얻는가?
                  드는 비용과 수고는 어떠한가?
                  문제가 생기면 누가 해결하는가?
                              |
                              v
                  이 비교에서도 나를 고를 이유는?
```

고객이 직접 Agent를 쓰는 것보다 나에게 맡기는 편이 나은가?
- 현장 조건을 확인하거나 잘못된 근거를 바로잡아, 고객이 직접 처리할 때보다 원하는 결과를 더 확실하게 얻도록 할 수 있는지 봄
- 고객이 직접 Agent를 써도 충분한 결과를 얻는다면, 같은 초안을 대신 만들어 주는 것만으로는 나를 선택할 이유가 약해질 수 있음
- 현장 확인, 조율과 후속 작업도 계속 사람에게만 남는다고 정하지 않고, 실제로 고객에게 남아 있는 부담이 무엇인지 봐야 함

Agent를 쓰는 다른 사람과 비교해도 나를 선택할 이유가 있는가?
- 나만 Agent를 쓰는 것이 아니므로, 같은 일을 더 싸거나 편하게 제공하는 경쟁자가 생길 수 있음
- 특정 제품과 고객에 대한 경험, 직접 확인한 정보, 필요한 사람의 협조를 얻는 능력이 결과에 어떤 차이를 만드는지 확인
- 그 차이를 고객이 필요로 하고, 나에게 지급하는 비용을 감수할 만큼 가치 있다고 보는지가 중요

# sources: 근거 문서의 사본과 그 출처

이 폴더는 [sources.md](../sources.md)가 가리키는 vault 안의 문서를 복사해 둔 곳입니다. 2026-10-15에 복사했습니다.

- 복사한 방식: 원래 문서를 통째로 복사하고, 저장소 안을 가리키는 링크는 링크 글자만 남기고 걷어 냈습니다. 외부 주소 링크와 문서 안의 앵커 링크는 그대로 두었습니다.
- 줄 수: 모든 사본의 줄 수가 원래 문서와 같습니다. 그래서 sources.md가 적은 행 번호를 사본에서 그대로 찾을 수 있습니다.
- 커밋 검사에 맞춰 고친 줄: 링크를 걷어 낸 것 말고도, 일곱 사본에서 모두 73줄을 고쳤습니다(아래 표의 "고친 줄" 칸). 고친 것은 다음과 같습니다.
  - 금액의 `$`를 `\$`로 바꿈
  - 가운뎃점을 쉼표로, 둥근 따옴표를 `'`로, 긴 대시를 `-`로 바꿈. 인용 안의 글자도 바꿨습니다.
  - 근거 경로를 달라는 줄 다섯에, 원래 링크가 가리키던 경로를 글자로 적거나 사본 안의 링크를 붙임
  - 절 번호만 적힌 줄 셋에 괄호 설명을 붙임. agent-payment-hackathon-scout.md 299행의 괄호 설명은 그 절 번호가 원래 문서에 정의되어 있지 않아서, 그 문장의 내용으로 에이전트가 붙였습니다.
  - "실측"을 "실제로 측정한 값"으로 바꿈
- 원래 문서가 다시 인용한 원문(공시, 보고서, 공고 등)과 그 행 번호는 이 폴더에 없습니다. 원문은 sources.md에 적은 외부 주소로 확인합니다.

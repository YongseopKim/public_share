# Arc 리서치의 구조 설계와 부분별 조사 대화

Arc 관련 해커톤과 빌더 프로그램에 참여하기 전에 무엇을 조사하고 어떤 결과물을 만들지 ChatGPT, Claude, Grok에 물은 대화다. 사용자는 공통 설명에 프로토콜, 사업전략, 개발과 토큰 관점의 질문을 붙이고, 개념과 관계를 먼저 설명한 뒤 구체화하는 목차를 요청했다.

## 원본과 검색본

원본 JSONL은 `raw/`에 보존한다. 원래 파일명, 대화 URL, 내보낸 시각과 이동 전 SHA-256은 manifest.json에 있다. 검색본은 발화 내용을 바꾸지 않고 `normalize-ai-chat-export.py`로 생성했다.

| 모델 | 원본 | 검색본 | 캡처의 한계 |
|---|---|---|---|
| ChatGPT | chatgpt.jsonl | chatgpt.md | 교차 평가에 붙여 넣은 사용자 입력이 내보내기에 남지 않았다. |
| Claude | claude.jsonl | claude.md | 교차 평가 입력은 첨부 이름으로만 남았다. |
| Grok | grok.jsonl | grok.md | 교차 평가 입력 본문이 남아 다른 두 캡처의 누락을 대조할 수 있다. |

한 행은 모델별 대화 하나다. ChatGPT와 Grok의 발화 시각은 내보낸 시각과 거의 같아서 실제 대화 시각으로 사용하지 않는다. Claude의 발화 시각과 내보낸 시각을 구별한다.

## 결과물과 쓰이는 곳

상세 원고 개정 계획에 따라 원본 보존 통합, 설명 비교와 이해 및 선택 검증을 거쳐 각 상세 원고를 작성했다. 원고별 자체 리뷰에서 구조와 근거를 따로 검토한 뒤 두 결과를 대조하고 수정한 전체 본문을 다시 읽었다. 다음 표는 읽을 파일을 담당 부분과 단계별로 연결한다.

| 담당 부분 | 원본 보존 통합 | 설명 비교 | 이해 | 상세 원고 | 자체 리뷰 |
|---|---|---|---|---|---|
| 조사 목적과 자료 관리 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 공통 개념 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 필요성과 대안 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 프로토콜 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 기업 업무 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 개발 접근 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 가치와 토큰 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 현재 상태 | 통합 | 비교 | 이해 | 원고 | 리뷰 |
| 종합과 참가안 | 통합 | 비교 | 이해 | 원고 | 리뷰 |

부분별 상세 원고 뒤 전체 이해를 작성하고 읽은 다음 전체 검토를 수행했다. 피드백과 반영 범위에 수정이 발생한 단계와 실제 목적지 및 이번 결과의 경계를 남겼다. 전체 이해와 검토의 최초 기록은 역사로 보존하고 후속 절을 구별했다.

최종 검사는 원본 및 검색본의 바이트, 통합의 원본 대응과 도식 구역 및 새 작성 문장의 형식을 검사한다. 전체 실행과 접수는 작성 당시 worktree의 버전과 단계 기록이다. 병합 후에는 병합본 검사 명령으로 현재 파일을 임시 디렉토리의 당시 경로에 복사하고 기존 접수를 재검사한다. 병합 전 검사 결과에 실제 결과를 남겼다. 기존 접수와 의미 검토의 이력은 보존하며 새로운 의미 검토로 세지 않는다. 모든 외부 사실의 독립적인 확인을 이 기계 검사로 대신하지 않는다.

Arc 리서치 구성은 목차와 조사 질문, 요청문 및 원고의 연결을 유지한다. 각 외부 서비스가 접근 가능한 자료를 직접 조사한다는 조건은 그대로 유지한다. 작업 결과는 이 묶음의 `outputs/`에 두고, 최종 리서치의 편집 및 통합은 이후 `cb/derived/`에 작성한다. 실제 계정 승인과 배포 및 지급, 고객과 개인 자격은 확인한 문서의 범위를 넘어 확정하지 않았다.

리서치 구조 판독은 초기 사용자 요구와 교차 노출 및 조사 설계를 읽는 별도 기록이다. 공식 조건의 선택 판독은 반환 자료 판독과 각 부분의 판독 및 변환 기록에서 읽는다. Circle과 Arc 허브는 관련 원자료로 이어 읽는 입구다.

## 조사 목적과 자료 관리의 반환 답변

부분별 요청문에 대한 반환 답변을 같은 묶음에 추가했다. 사용자가 새 Claude 파일을 대체본으로 지정했으므로 종합에는 대체본을 사용한다. 이전 캡처는 보존하며 별도 독립 답변으로 세지 않는다.

| 서비스와 버전 | 원본 | 검색본 | 내용과 확인 범위 |
|---|---|---|---|
| ChatGPT | scope-chatgpt.jsonl | scope-chatgpt.md | 프로그램별 조건과 접근 권한, 시점 기록 및 조사 순서를 제안한다. 이번 요청 본문이 남아 있다. |
| Claude 대체 전 | scope-claude.jsonl | scope-claude.md | Microgrants를 접수 중으로 확인한 유일한 프로그램이라고 결론 낸 이전 답변이다. 첨부 요청 본문은 캡처되지 않았다. |
| Claude 대체본 | scope-claude-replacement.jsonl | scope-claude-replacement.md | 요약 도구를 통한 열람과 Microgrants 1차 공고 접근 실패를 밝힌다. 유일 후보 및 자동 제외 전제는 작업 원고에서 수정했다. 첨부 요청 본문은 캡처되지 않았다. |
| Grok | scope-grok.jsonl | scope-grok.md | Tameion 일정 차이와 Questbook 회차 상태를 제시한다. 일부 미확인 행사를 후보에서 제외한 판단은 원고에서 수정했다. 이번 요청 본문이 남아 있다. |

원래 파일명, URL, 내보낸 시각, 이동 전 해시는 반환 manifest와 대체 manifest에 있다. 같은 Claude 대화 URL의 재내보내기이며 독립적인 추가 응답으로 취급하지 않는다.

조사 목적과 자료 관리 작업 원고는 공개 조건을 확인한 프로그램과 확인 대기 후보, 시점 기록과 다음 조사 순서를 정리했다. 답변의 모든 기술 주장을 판독한 것은 아니다. 원고에서 사용한 공식 자료는 프로그램 조건 대조 묶음에 이어 보존했다. 구조와 링크 검사, 별도 인용 검증과 수정, 원본 무결성 검사를 함께 남긴다.

## 부분별 조사 반환과 작업 원고

구성 문서의 각 요청에 ChatGPT, Claude와 Grok이 반환한 조사 자료를 같은 묶음에 추가했다. 아래 표의 한 행은 부분별 조사 하나다. 원본과 검색본을 구별해 연결하며 원문, URL, 내보낸 시각과 이동 전 해시는 부분별 manifest에 남겼다.

| 담당 부분 | ChatGPT 원본과 검색본 | Claude 원본과 검색본 | Grok 원본과 검색본 | 작업 원고 |
|---|---|---|---|---|
| 무엇인가 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 왜 필요한가 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 프로토콜 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 기업 결제 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 개발 접근 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 가치와 토큰 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 현재 상태 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |
| 조사 결과와 참가안 | 원본, 검색본 | 원본, 검색본 | 원본, 검색본 | 원고 |

섹션별 통합 이해는 세 답변의 공통 내용, 보완과 충돌을 재구성한다. 원고 작성 뒤 별도 파일로 보완했고 전체 원고 검토에서 원고들과 다시 대조했다. 반환 자료 판독은 선택 검증과 원고의 채택 근거를 기록한다. Claude의 요청 입력은 첨부 이름으로만 남아 실제 첨부 내용을 복원하지 않았다. 서비스별 일치나 같은 답변의 부가 블록을 원자료의 독립 확인으로 세지 않는다.

원문 열람 범위 검사는 관찰자의 완료 문장 대신 실제 도구 출력과 원본의 연속 행을 대조한다. 선택 인용 검사와 최종 검사 기록을 함께 남긴다. 공식 자료를 보완한 수집본은 공식 자료 묶음에 있다. 원고는 `outputs/`에 두며 통합 리서치는 이후 별도로 작성한다.

## 검색본 검증 명령

```sh
python3 cb/meta/normalize-ai-chat-export.py --verify cb/works/ai-chat/2026-10-05-arc-research-structure
```

원문과 검색본의 일치를 검사한다. 내용의 사실성은 판독에서 따로 다룬다.

2026-10-15의 시각화 적용 기록과 영문 기록은 안내문과 해당 Arc 원고의 표현 개정을 다룬다. 기존 사실의 기준일과 원본 그림을 옮긴 부분은 유지했다.

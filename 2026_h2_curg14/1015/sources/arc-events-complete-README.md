# Arc 이벤트 저장 화면 전체와 연결된 공개 자료

사용자가 Downloads에 저장한 웹아카이브를 기준으로 모든 이벤트 카드의 상세를 다시 수집한 묶음이다. 기존 부분 조사를 전체 참여 기회처럼 안내했던 문서를 교체하려고 만들었다.

- 전체 행사별 정리에서 각 공고의 목적, 개발 주제, 조건, 지원, 일정과 세션을 읽는다.
- 연결자료 정리에서 주최자 규칙, 등록 및 제출 질문과 공개 다시보기의 텍스트를 읽는다.
- 제품 주제 비교는 전체 공고를 읽은 뒤 수정한 비교 안내다.
- 출처 지도, 미확인 내용과 리뷰를 함께 읽는다.

원본 화면의 이벤트 카드와 최종 행사별 정리는 각각 178개와 178개다. 연결자료는 134개 주소를 요청했으며 124개에서 HTTP 200 응답을 받았고 10개는 실패했다. HTTP 200은 신청 양식이나 동적 본문 전체가 표시되었다는 뜻이 아니다. 수치는 `python3 cb/works/web/2026-10-08-arc-events-complete/outputs/run/verify_coverage.py --report`의 저장 결과에서 가져왔다. 이는 상세 페이지와 주소의 수이며 독립된 프로그램의 수가 아니다.

## 추가 저장 화면: 실패했던 주소의 본문을 보완했다

웹아카이브 보완 정리는 Microgrants의 제출 양식, Mumbai 해커톤의 모든 포함된 FAQ와 일정, Cannes 서밋의 강연 및 FAQ, Pragma Mumbai의 티켓과 참가 조건을 읽는다. 저장 원본은 아래 목록에 있고 Downloads 파일은 변경하지 않았다.

- Arc Microgrants | Circle | Hackathon | DoraHacks.webarchive: https://dorahacks.io/hackathon/arc-microgrants의 저장 원본이다. 전체 검색 표현을 연결했다.
- ETHGlobal Mumbai.webarchive: https://ethglobal.com/events/mumbai의 저장 원본이다. 전체 검색 표현을 연결했다.
- Pragma Cannes 2026.webarchive: https://ethglobal.com/events/pragma-cannes2026의 저장 원본이다. 전체 검색 표현을 연결했다.
- Pragma Mumbai.webarchive: https://ethglobal.com/events/pragma-mumbai의 저장 원본이다. 전체 검색 표현을 연결했다.

네 저장 원본으로 실패 주소 다섯 개의 본문을 확보했다. Mumbai의 슬래시 유무 두 주소는 한 원본을 공유한다. Coindesk와 Luma의 네 주소는 사용자께서 404라고 확인했고 가입 주소는 사용자 판단으로 검토에서 제외했다. 초기 요청 결과 124건의 HTTP 200과 10건의 요청 실패는 당시의 기록으로 유지한다. 복구를 당시 HTTP 200으로 바꾸어 세지 않는다. 현재 주소별 상태는 주소 처리 기록, 대조 명령과 결과는 `python3 cb/works/web/2026-10-08-arc-events-complete/outputs/user-archives-run/verify.py` 및 추가 원본 검사에 있다.

기존 변환 실행 기록은 최초 전체 조사 판본에 결합된 역사 기록이다. 추가분과 변경한 안내의 검토 버전은 추가 실행 기록과 추가 리뷰에 따로 결합한다. 기존 검사 결과를 현재 문서 전체의 새 검사로 읽지 않는다.

## 원본과 검색 표현

원본 웹아카이브는 사용자의 파일을 그대로 보존한 사본이다. 사용자의 Downloads 파일은 변경하지 않았다. 웹아카이브의 주소와 SHA-256은 원본 기록에 있다.

raw/events/에는 각 상세 요청의 원본, raw/linked/에는 연결자료 원본과 실패 응답을 보관한다. raw/는 편집하지 않았다. 행사별 수집 목록과 연결자료 수집 목록이 요청 주소, 실제 응답, 파일 및 해시를 연결한다.

pages/events/의 Markdown과 JSON은 설명 본문과 전체 공개 이벤트 데이터를 보존한다. pages/reading-inputs/는 관찰자에게 전달한 본문과 공개 조건 데이터다. pages/linked/는 공개 연결자료의 전체 가시 텍스트이며 PDF에는 쪽 경계가 있다. 시각 확인은 행사장 이미지와 백서의 서로 다른 열람 범위를 설명한다.

## 검증과 사용처

원본 객체 검사는 저장 화면의 모든 상세 주소와 원본 이벤트 객체 및 설명의 텍스트를 대조한다. 연결자료 원문 검사는 원본 HTML의 가시 텍스트와 이미지 대체텍스트 및 PDF 전체 텍스트를 검색 표현과 대조한다. 실제 열람 검사는 보고서의 인용과 실제 도구 출력에 나타난 원문 행을 대조한다.

변환 실행 기록에 중간 재구성, 출처 추적과 검토한 버전을 연결했다. 내용은 LLM이 작성한 이해 전용 재구성이다. 실제 개최, 기술 성능과 개인의 참가 승인에 대한 외부 사실 판독은 실행하지 않았다.

사용처는 Circle과 Arc 허브와 참여 조건 및 판단 기준이다. 원본은 로컬 보존 대상이며 대용량 raw 파일은 git에서 제외하는 vault의 기존 정책을 따른다.

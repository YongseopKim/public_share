# Arc 프로그램과 행사 참가 조건: 저장 화면의 공고를 읽는다

이 문서는 저장 화면의 본문, 포함된 FAQ 답변과 제출 양식을 정리한다. 공고의 설명과 실제 참가 승인 및 현재 웹사이트 상태를 구분한다. 아래의 정보는 저장된 판본에 대한 주최자 설명이다.

## 1. Arc Microgrants: 먼저 배포한 작은 결과물을 기한 안에 제출한다

DoraHacks 본문의 제목은 "Arc Microgrants | Circle"이다. [저장 본문과 제출 객체](https://dorahacks.io/hackathon/arc-microgrants)는 Circle이 Arc 메인넷에서 작동하는 작은 앱, 개념 증명, 시제품, 데모, 실험적 인프라와 해커톤 후속 개발을 지원한다고 설명한다. 회사, 사용 실적, 발표 자료와 로드맵은 요구하지 않는다. 개인 개발자, 학생 팀, 해커톤 팀, 첫 창업자와 초기 인프라 팀을 대상으로 하며 처음 체인에 배포하는 개발자도 환영한다.

핵심 표현은 "Build first, then submit"이다. 먼저 Arc 메인넷에 작동하는 결과물을 배포한 뒤 열린 링크와 저장소를 제출한다. 사전 참여 확약이나 이후 후속 보고를 요구하지 않는다고 설명한다. 다만 이 판본은 제출 마감이 있는 특정 모집 공고다. 무기한 상시 접수라는 뜻으로 읽지 않는다.

### 1.1. 지원과 심사: 작동하는 첫 결과물에 보조금을 지급한다

공고는 500 USDC씩 20건, 총 10,000 USDC를 안내한다. 지원금을 Arc에서 USDC로 지급하며 지분 희석이 없다고 설명한다. 기술 안내, 생태계 기술 상담(office hours), 커뮤니티 소개, 필요한 연결과 Circle Grant Program으로 이어지는 경로를 제시한다. Arc 관련성, 기술적인 신뢰성, 구현 품질과 계속 개발할 가능성을 본다. 사용 실적보다 가능성에 더 주목한다고 적는다.

개발과 메인넷 배포, 링크와 저장소 제출, 완결성과 적합성 검토, 후보 채점 및 묶음 결정, 지급 대상자의 짧은 검증, 지급 순서다. 제출에는 약 10분이 걸린다고 설명한다. 본문의 마감은 2026년 10월 14일 23:59 ET이며 접수되는 대로 검토하고 10월 21일까지 모든 결정을 알린다고 적는다. 빨리 제출하면 더 일찍 답을 받는다고 안내한다. 화면은 2026/09/16 19:00부터 2026/10/15 12:59까지 표시하며 구조화 데이터의 종료는 2026-10-15T03:59:00.000Z다. 화면 시각의 시간대는 임의로 붙이지 않는다.

### 1.2. 제출물: 배포 링크, 공개 코드와 검증 가능한 거래를 요구한다

본문은 작동하는 메인넷 배포 링크, 공개 저장소, 프로젝트 기능과 Arc 사용 목적의 짧은 설명, GitHub 또는 X 또는 Farcaster의 공개 개발자 프로필을 요구한다. 저장된 제출 객체에는 다음 질문이 있다. 괄호의 필수 여부는 저장된 양식의 required 값을 따른다.

- 프로젝트 이름 (필수).
- 본인 이름, 별명 또는 팀 이름 (필수).
- 연락 이메일 (필수).
- 공개 개발자 프로필: GitHub, X, Farcaster (필수).
- Arc 메인넷의 실제 배포 링크 (필수).
- 검증 가능한 Arc 메인넷 계약 주소 또는 거래 해시 (필수).
- 공개 저장소 (필수).
- 두 문장으로 설명한 프로젝트 기능 (필수).
- Arc를 사용하는 목적 (필수).
- 이 프로젝트 전에 Arc에 배포한 경험: Mainnet, Testnet, No 중 선택 (필수).
- 이 프로젝트에 대해 Circle 또는 Arc의 grant, bounty, prize를 받은 적이 있는지: Yes, No 중 선택 (필수).
- 추가로 보여 줄 내용 (선택).

저장 객체는 코드 저장소 링크를 필수로 지정하고 영상 링크는 필수로 지정하지 않는다. 본문은 디자인 목업, 발표 자료만 있는 작품, 테스트넷 전용 작품, Arc 구성요소가 없는 작품과 이미 Circle 또는 Arc 프로그램에서 자금을 받은 작업을 제외한다. 해커톤 작품은 메인넷에 배포되어 작동해야 한다. 해커톤 작품을 허용한다는 문장만으로 이미 상금을 받은 작업의 중복 지원까지 승인됐다고 확정하지 않는다.

### 1.3. 권리와 지급: 전 세계 신청을 허용하되 지급 검증을 거친다

전 세계 개인과 팀에게 열려 있지만 제재 및 제한 관할지역 심사를 거친다고 적는다. 가명 제출이 가능하며 조건부 선정 후 실제 지원금 수령자만 비공개로 신원 검증을 한다. 신원을 공개할 필요는 없다고 설명한다. 프로젝트마다 제출은 한 번이며 팀은 서로 다른 프로젝트를 여러 개 낼 수 있다.

작업은 본인의 것이거나 제출 권리가 있어야 한다. Arc의 USDC를 받을 수 있는 지갑이 필요하며 배포와 거래에는 가스 비용으로 소량의 USDC가 든다. 지분, 지식재산권과 독점권을 넘기지 않고 소유권을 유지한다고 적는다. 일정과 지급 건수는 조정될 수 있다.

본문의 질문 답변은 메인넷에서 실제 작동해야 하는지, 회사가 필요한지, 가명 제출 여부, 해커톤 작품 허용 여부, 답변 시점을 다시 설명한다. 답은 각각 메인넷 작동 필수, 회사 불필요, 지급 검증 때까지 가명 가능, 메인넷 배포한 해커톤 작품 가능, 접수 순차 검토와 10월 21일까지 결정이다. Microgrants는 첫 증명을 지원하고 Circle Grant Program은 제품을 실제 서비스로 발전시키는 과정을 지원한다고 구분한다. 더 진행된 프로젝트도 제출하면 적절한 프로그램으로 안내하겠다고 적는다.

면책은 Arc LLC가 출시한 공개 L1이 허가형 검증자 집합으로 운영되며 회사는 소프트웨어 서비스만 제공한다고 설명한다. 규제 금융 및 자문 서비스를 제공하거나 규제기관 승인을 받았다는 뜻이 아니라고 적는다. 스마트 계약 결함, 네트워크 장애, 거래 오류와 손실, 가스용 USDC 확보 문제를 명시하고 제3자 앱의 기능과 적법성은 해당 제공자가 책임진다고 설명한다. 기능의 변경, 지연과 취소 가능성을 밝히며 보장이나 법률, 규제, 세금과 투자 조언이 아니라고 적는다. 이는 공고의 자기 설명이며 외부 법적 판단은 하지 않았다.

## 2. ETHGlobal Mumbai: 현장 해커톤의 새 안내와 FAQ를 함께 읽는다

[저장 화면과 전체 FAQ](https://ethglobal.com/events/mumbai)는 2026년 11월 5일부터 7일까지 Mumbai의 Jio World Convention Centre에서 열리는 현장 해커톤을 안내한다.

본문은 참석자 800명 이상, 프로토콜 11개 이상, 워크숍 29개 이상, 초보자 참여, 기술 멘토링, 기념품, 선정된 학습 자료와 무료 음식을 설명한다. 주제는 영지식 증명, AI와 암호화폐, DeFi, 소비자 앱, Layer 2, 상호운용성, 공공재, 개인정보 보호와 보안, 신뢰 실행 환경(TEE), 데이터 가용성, 신원과 개발 도구다. Ethereum 위에서 원하는 아이디어를 개발하며 특정 문제만 풀도록 제한하지 않는다고 FAQ에서 설명한다.

### 2.1. 개발 방식과 상금: 기존 코드 허용 안내에도 충돌이 남아 있다

새 안내는 팀 1명부터 5명, 가져온 저장소에서 개발 가능, 기존 코드 환영, 후원자 SDK 최대 3개를 제시한다. 처음부터 만드는 From Scratch, 자신이 관리하는 공개 저장소를 확장하는 Extend Open Source, 기존 제품에 행사 중 새 기능을 만들고 공개 소프트웨어로 배포하는 Ship a Feature를 구분한다. FAQ에는 사전 개발 금지와 기존 프로젝트를 이어 가는 팀의 최종 후보 제외 안내도 남아 있다. 어느 문장이 최종 규칙인지 이 저장 파일만으로 확정하지 않는다.

화면의 총상금은 175,000 USD이며 Arc는 15,000 USD로 따로 표시된다. 개별 표시액은 0G, Uniswap Foundation, Arc, Hedera, Arkiv, Whitechain, Ethereum Foundation이 각각 15,000 USD이고 World가 12,500 USD, ENS가 10,000 USD, 1inch가 7,000 USD, Definitive와 Chainlink가 각각 5,000 USD다. 화면의 총액과 개별 파트너 값 및 내부 데이터의 상금 필드는 같은 분모라고 가정하지 않는다. 저장 데이터에서 1inch의 prizeAmount는 20,000이고 totalPrizeAmount는 7,000으로 다르다.

파트너 자료는 Hedera를 Solidity와 JavaScript SDK를 사용하는 EVM 체인으로, Definitive를 여러 체인의 유동성을 고급 주문과 REST API 및 MCP에 연결하는 도구로 소개한다. Ethereum Foundation은 검열 저항성, 개방성, 개인정보 보호와 보안이라는 개발 지향을 설명한다. 개별 Arc 상금의 상세 규칙은 [별도 상금 페이지](https://ethglobal.com/events/mumbai/prizes/arc)에서 확인해야 한다.

### 2.3. FAQ: 신청, 사전 개발과 예치금 조건을 각 답변에서 구분한다

다음은 저장 객체의 FAQ마다 답변을 재구성한 목록이다. 질문 제목과 아래의 FAQ 번호는 주최자 데이터의 원래 항목을 찾는 데 쓴다. 번호만으로 규칙을 인용하지 않고 원문 질문과 답변을 함께 확인한다.

- "Who can attend this event?": 행사 중 프로젝트를 만들거나 기여하려는 개발자와 빌더를 대상으로 한다. [원문](https://ethglobal.com/events/mumbai).
- "Can I use AI to build my project?": AI 도구 사용은 일반적으로 허용한다. 생성하거나 보조한 코드, 파일과 자산 및 사용 방법을 제출물에 명시해야 한다. 팀원의 의미 있는 기여 없이 AI에 전적으로 의존한 작품은 파트너 상금과 최종 후보에서 제외될 수 있다. [원문](https://ethglobal.com/events/mumbai).
- "How many Partner Prizes can I apply for?": 프로젝트당 파트너를 최대 3곳 선택할 수 있다. 각 파트너의 도구 사용 및 통합, 피드백과 의견을 설명한다. 한 파트너의 여러 부문은 한 곳으로 계산하며 ETHGlobal 최종 후보 부문은 별도다. [원문](https://ethglobal.com/events/mumbai).
- "Do I need to submit an application if I'm already part of a team?": 팀원마다 개인별로 신청하고 참가 확약금(stake)을 예치해야 한다. 팀 소속과 관계없이 개인별로 심사한다. [원문](https://ethglobal.com/events/mumbai).
- "What can I build during the event?": Ethereum을 기반으로 자신이 원하는 아이디어를 개발할 수 있다. 특정 문제를 풀도록 제한하지 않으며 멘토, 기술 지원과 파트너 SDK 및 상금이 제공된다고 설명한다. [원문](https://ethglobal.com/events/mumbai).
- "How many members are allowed on my team?": 팀은 최대 5명이며 각자 신청하고 예치해야 한다. 개인 참여도 가능하지만 시간 제약 때문에 2명 이상을 권한다. 행사 전과 행사 중 팀 구성 기회를 제공한다. [원문](https://ethglobal.com/events/mumbai).
- "Can I participate remotely at this event?": 현장 참여만 허용한다. 현장에 참석하지 않으면 참가 철회로 처리하며 온라인 참여를 지원하지 않는다. [원문](https://ethglobal.com/events/mumbai).

## 4. Pragma Mumbai: 해커톤과 연결된 별도 유료 서밋을 구분한다

[저장 본문과 티켓 데이터](https://ethglobal.com/events/pragma-mumbai)는 2026년 11월 6일 Jio World Convention Centre에서 열리는 Web3 개발자와 관계자 대상 서밋을 안내한다. 본문과 객체의 행사 날짜가 일치하지만 기존 Arc 공고들에 있는 다른 날짜는 덮어쓰지 않는다. 기존 ETHGlobal Mumbai 해커톤의 자녀 행사이며 자신의 부모 행사도 ETHGlobal Mumbai로 기록된다. 연결된 행사라는 뜻이지 해커톤 신청이 서밋 입장을 자동으로 승인한다는 뜻은 아니다.

동시 세션 없이 소규모 창업자와 개발자들이 Web3의 미래와 과거를 토론한다고 설명한다. Invite only, 선정된 내용, 초보자 참여와 가까운 토론을 특징으로 적는다. Get Tickets 및 Apply to attend와 티켓 구매 버튼도 함께 있다.

### 4.1. 티켓과 제공 내용: 해커용 할인과 일반 입장을 구분한다

화면은 Early bird ticket으로 Network Pass 29 USD(점심 없는 일반 입장), Hacker 49 USD(ETHGlobal Mumbai 참가 확정자), General 69 USD(일반 입장)를 표시한다. 강연, 인터뷰와 패널, 발표자 및 참가자 교류, 음료와 간식을 안내하며 General에는 친구에게 줄 무료 Network Pass가 포함된다고 설명한다. ETHGlobal Plus는 828 USD로 1년간 Pragma 및 여러 부대 행사 접근, eSIM과 호텔 할인, 무료 온체인 거래를 안내한다. 연간 상품의 제공 설명을 해당 서밋의 단일 입장권으로 합치지 않는다.

화면 파트너는 Uniswap, 0G, World, Arc, Arkiv, 1inch와 Ledger다. 포함된 sponsors 객체에는 Whitechain도 있다. 아직 화면에 표시되지 않은 후원자라고 기록하며 추가 행사를 뜻한다고 추정하지 않는다. 저장 객체의 people, schedule, scheduleItems, faqs 목록은 모두 비어 있다. 따라서 발표자나 세부 일정 및 FAQ 답변을 다른 도시 행사에서 가져와 채우지 않는다.

행사 객체는 signupDeadline 2026-11-05T03:30:00.000Z와 submissionDeadline 2026-11-05T18:29:00.000Z를 함께 담는다. 서밋이므로 이 필드들을 해커톤 작품 제출 마감으로 설명하지 않는다. 실제 적용 의미와 구매 이후 절차는 저장된 본문만으로 확정하지 않았다.

## 5. 열람 범위

이 재구성은 LLM이 작성했다. 텍스트와 포함된 공개 객체를 읽었으며 행사 개최와 기술 성능, 개인 참가 승인, 실제 웹사이트의 현재 상태를 외부 증거로 판정하지 않았다. 사진, 로고와 도면의 이미지 내용, 별도로 열어야 하는 화면과 실제 신청 실행은 확인하지 않았다.
